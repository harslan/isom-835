Your first model

Twelve lines of Python

import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression

df = pd.read_csv('…/telco_churn.csv')
X = pd.get_dummies(df[['tenure', 'MonthlyCharges', 'Contract']], drop_first=True)
y = (df['Churn'] == 'Yes').astype(int)

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=835)   # the most important line

model = LogisticRegression(max_iter=1000).fit(X_train, y_train)
pred  = model.predict(X_test)                            # customers it has never seen
Why hold out data

Train on 5,634 · Test on 1,409

Training set · 80%
The model learns here

Coefficients are fit to these customers only.

Test set · 20%
The model is judged here

Customers it has never seen. Its score here is a forecast of next month, not a memory of last month.

stratify=y keeps the churn rate identical in both halves — 26.5% on each side.

Why accuracy lies

Three questions for any accuracy number

  • Compared with what baseline? 79% against a 73.5% do-nothing model is a 5.6-point gain, not a 79-point one.
  • On which data? Held-out customers, or the ones the model memorized?
  • At what cost per mistake? A wasted offer costs $50. A missed churner costs a $1,500 customer.
